# Changelog

All notable changes to this project follow [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) and adhere to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2025-10-12

### Added
- `Merge Output With Input` option to preserve original items.
- Utility module (`nodes/Centroid/utils.ts`) with validation and reusable logic.
- Vitest unit tests with 80% coverage threshold.
- GitHub Actions workflow for lint, test and build checks.
- Project documentation (`README.md`, `CONTRIBUTING.md`, `REQUIREMENTS.md`, `SECURITY.md`) and usage examples.

### Changed
- Centroid calculation now processes each input item independently and validates numeric values.
- Updated package metadata, scripts and licensing information.

### Removed
- Template example nodes and credential stubs.

## [1.0.0] - 2025-10-12

### Added
- Initial release of the Centroid n8n node.
